# Images Folder

All images for the portfolio website live here.

## Naming Convention

Images are prefixed by project:

| Prefix | Project | Page |
|--------|---------|------|
| `CS-`  | ChainSync | `chainSync.html` |
| `gdm-` | GDM | `gdm.html` |
| `op-`  | Operation Platform | `op-platform.html` |
| `ra-`  | Retail App (Sodimac) | `retail-app.html` |

Homepage thumbnails and shared images use descriptive names.

## Guidelines

- **PNG** for screenshots and UI elements, **JPG** for photos
- Compress to < 500KB per image (TinyPNG, Squoosh, ImageOptim)
- Case study images: at least 1200px wide
- When adding images, use the project prefix and update this file
